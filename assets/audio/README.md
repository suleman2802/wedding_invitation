# Background music

Save the background track here as `music.mp3` (`.m4a` and `.ogg` also work,
named `music.m4a` / `music.ogg`).

Use a track you have the rights to — e.g. a royalty-free soft instrumental
downloaded from Pixabay Music or a similar library.

Behaviour once the file is present:
- Music starts (looping, soft volume) when a guest taps the envelope open.
- A floating button on the invitation lets guests pause/resume it.
- If no file is present, the button is hidden and nothing plays.

After adding the file, rebuild: `flutter build web --release`.

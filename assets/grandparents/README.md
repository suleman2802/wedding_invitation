# Grandparents portraits

Save the two portrait photos here, named:

- `grandfather.jpg` (or `.png` / `.webp`)
- `grandmother.jpg` (or `.png` / `.webp`)

When both files are present, the envelope screen shows them in gold-framed
circular portraits above the envelope with a blessing line — as if they are
presenting the invitation. If either file is missing, the envelope screen
simply shows the envelope alone.

After adding files, rebuild: `flutter build web --release`.
